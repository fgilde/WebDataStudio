# Kontakt und Unterstützung

Eine Frage, die die Doku nicht beantwortet, eine Idee oder ein Fehler, der nicht ganz ein
GitHub-Issue ist: schreib. Und wenn dir das Studio Zeit spart, hält ein Kaffee das nächste Release
am Laufen.
